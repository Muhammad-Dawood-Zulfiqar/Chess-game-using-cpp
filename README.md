# ♟️ Chess Game

## 📖 Description
A fully functional, interactive 2D chess game built entirely in C++. This project brings the classic board game to the desktop, utilizing the SFML graphics library to render a clean user interface and handle player interactions. It strictly follows all standard chess rules and provides visual aids to enhance the gameplay experience.

## ✨ Key Features
* **Visual Move Highlighting:** Clicking on any piece instantly calculates and highlights all of its legal moves on the board, making it highly intuitive to play.
* **Complete Chess Logic:** Automatically detects and handles complex game states including Check, Checkmate, and Stalemate.
* **Special Moves Supported:** Includes full functionality for advanced mechanics like Pawn Promotion.
* **Match Timer:** Features a built-in timer system to keep track of the game pace and add a competitive edge.
* **Interactive UI:** Smooth mouse-driven controls powered by SFML.

## 🛠️ Tech Stack
* **Language:** C++
* **Graphics Library:** [SFML](https://www.sfml-dev.org/) (Simple and Fast Multimedia Library)

## 🚀 Dependencies & Setup
To run or compile this project locally, you will need:
1. A C++ compiler (like GCC or MSVC via Visual Studio).
2. **SFML** installed and properly linked to your C++ environment.
3. The image assets (pieces, board background) placed in the correct directory as referenced in the code.

## 🎮 How to Play
1. **Select a Piece:** Use your mouse to left-click on any of your pieces.
2. **View Legal Moves:** The board will highlight all valid squares you can move to.
3. **Make a Move:** Click on one of the highlighted squares to move your piece. 
4. **Win the Game:** Trap the opponent's king to achieve Checkmate!
